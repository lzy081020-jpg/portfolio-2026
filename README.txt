赖征宇 AI Portfolio — 最终整合版

使用方法：
1. 解压整个文件夹后，双击 index.html 即可打开。
2. 不要只复制单个 HTML；图片、视频、CSS、JS 和游戏都在同一项目中。
3. 可直接部署到 Netlify：把整个文件夹拖入 Netlify Deploys 即可。
